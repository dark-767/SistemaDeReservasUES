# Sistema de Reservas de Espacios y Recursos Institucionales

Sistema web para consultar disponibilidad y gestionar reservas de espacios y recursos institucionales.

## Tecnologías
- Backend: Django
- Base de datos: PostgreSQL
- Control de versiones: Git y GitHub
- Gestión ágil: Scrum y Jira

## Equipo
Proyecto académico desarrollado mediante metodología Scrum.
